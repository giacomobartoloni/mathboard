DESKTOP SETTINGS

Local assistants

Enable or disable local MCP access to MathBoard.

Before allowing access

When MCP is enabled, local assistants may access board content and screenshots. Local assistants can also edit or delete boards. Local transport does not guarantee local processing by an AI provider.

Reading native permissions…

Allow local MCP connections When enabled, apps on this computer can read, edit and delete local boards. Off by default; explicit CLI startup can enable it.

Loopback MCP endpoint

Copy the currently active URL into your local Streamable HTTP MCP client. If the preferred port is occupied, MathBoard automatically uses the next available port. No token or custom header is required.

MCP starts disabled unless explicitly enabled by the desktop CLI flag. Switching boards does not disable it. While enabled, other applications on this computer can connect without authentication.
